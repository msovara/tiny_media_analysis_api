The AI WeatherQuest Competition

A Global Challenge for Medium-Range Weather Prediction:

  • Organized by the European Centre for Medium-Range Weather Forecasts (ECMWF)
  • Focus on sub-seasonal forecasting (2-6 weeks ahead)
  • Using ERA5 reanalysis data as training material
  • Emphasis on probabilistic forecasting for uncertainty quantification

Competition Details:

  • Objective: Predict global 2-meter temperature with quantile probabilities
  • Resolution: 1.5-degree latitude/longitude grid
  • Lead Times: Days 19-25 and Days 26-32
  • Evaluation: Continuous Ranked Probability Score (CRPS)

Our Approach:

  • Leveraged the Anemoi framework for data processing and model development
  • Developed custom Lengau API to accelerate training on HPC infrastructure
  • Focused on models optimized for African climate patterns
  • Created reproducible workflows for knowledge sharing

Key Benefits for Africa:

  • Access to state-of-the-art forecasting techniques
  • Models tailored to African conditions
  • Knowledge transfer from global research community
  • Potential for operational implementation at national weather services

Anemoi Framework Implementation

Weather and Climate AI Toolkit: Anemoi is a specialized framework for weather and climate AI applications that we've implemented for the AI WeatherQuest competition.

Framework Components:

  • anemoi-datasets: Data ingestion, regridding, chunking, and Zarr output for ERA5 data, optimized for African regional forecasting
  • anemoi-models: UNet, ResNet, and Transformer architectures adapted for meteorological data and spatial patterns relevant to African climate
  • anemoi-training: Model training, hyperparameter tuning, and experiment tracking, integrated with our Lengau API for HPC acceleration
  • anemoi-inference: Operational deployment and evaluation of models, with specialized metrics for sub-seasonal forecasting performance

Example Code:

# Using Anemoi with our Lengau API integration from anemoi.datasets import ERA5Dataset from anemoi.models import UNetModel from anemoi.training import Trainer from lengau_api import LengauJob # Load and preprocess data dataset = ERA5Dataset( variables=["t2m", "mslp", "tp"], region="africa", resolution="1.5deg" ) # Create model model = UNetModel( input_vars=dataset.input_variables, output_vars=["t2m"], lead_time_days=21 ) # Train with Lengau HPC trainer = Trainer(model=model, dataset=dataset) job = LengauJob( script=trainer.get_training_script(), resources={"nodes": 2, "gpus": 4} ) job.submit()

Data Acquisition & Preparation

ERA5 Data Processing Pipeline:

  • Data Source: ERA5 reanalysis data from the Copernicus Climate Data Store, accessed via the CDS API
  • Variable Selection: Carefully chosen meteorological variables relevant for temperature forecasting in African contexts
  • Preprocessing: Custom download_era5.py script integrated with anemoi-datasets for efficient processing
  • Storage Format: Conversion to Zarr format for optimized parallel access on HPC systems

Example Code from download_era5.py:

import cdsapi c = cdsapi.Client() c.retrieve( 'reanalysis-era5-pressure-levels', { 'product_type': 'reanalysis', 'format': 'netcdf', 'variable': ['temperature'], 'pressure_level': ['850'], 'year': ['2020'], 'month': ['01'], 'day': ['01'], 'time': ['00:00'], 'area': [ -30, -15, -35, 20 ], # North, West, South, East }, 'era5_850hpa_temp.nc')

Integration with Lengau API:

  • Parallelizes data downloads across compute nodes
  • Optimizes storage access patterns for large climate datasets
  • Provides simplified interfaces for meteorologists without HPC expertise
  • Enables reproducible data workflows for African weather services

Key Variables and African Relevance:

  • t2m (tas): 2m Air Temperature - Critical for heat wave prediction
  • mslp: Mean Sea Level Pressure - Monsoon and pressure system tracking
  • tp (pr): Total Precipitation - Drought and flood forecasting
  • z: Geopotential Height - Atmospheric circulation patterns
  • u, v: Wind Components - Dust storms and tropical cyclones

Lengau Cluster Job Management API

Democratizing HPC Access for Weather Forecasting:

The Lengau API is our custom solution to bridge the gap between complex HPC infrastructure and meteorological services across Africa.

Key Features:

  • Simplified Job Submission: Abstracts away complex PBSPro scheduler syntax
  • Resource Optimization: Automatically determines optimal resource allocation
  • Workflow Management: Handles dependencies between data processing and model training
  • Error Handling: Robust recovery mechanisms for network or node failures
  • Monitoring: Real-time status updates and performance metrics

Code Comparison:

Traditional PBS Script (Complex):

#!/bin/bash #PBS -N weather_model #PBS -l select=2:ncpus=24:mpiprocs=24 #PBS -l place=scatter:excl #PBS -l walltime=24:00:00 #PBS -q normal #PBS -P PROJ123 module load python/3.10 cd $PBS_O_WORKDIR mpirun -np 48 python3 train_model.py \ --data /scratch/data/era5 \ --output /scratch/results \ --epochs 100

With Lengau API (Simplified):

from lengau_api import LengauJob # Simple, intuitive interface job = LengauJob( name="weather_model", script="train_model.py", data_path="/scratch/data/era5", output_path="/scratch/results", params={"epochs": 100} ) # One line to submit job.submit() # Easy monitoring job.monitor()
